  HOSTINGER DEPLOYMENT INSTRUCTIONS
  Tina Yene Bakery Website
═══════════════════════════════════════════════════════════════════

DEPLOYMENT PACKAGE CONTENTS:
  ✓ .next/              - Pre-built Next.js application
  ✓ public/             - Static assets and images
  ✓ prisma/             - Database schema and migrations
  ✓ app/, components/   - Application source code
  ✓ lib/, store/, etc.  - Utilities and libraries
  ✓ Configuration files - next.config.mjs, tsconfig.json, etc.
  ✓ package.json        - Dependencies manifest
  ✓ pnpm-lock.yaml      - Locked dependency versions

NOT INCLUDED:
  ✗ node_modules/       - Will be installed on server
  ✗ .env                - Must be created on server
  ✗ .git/               - Version control not needed

═══════════════════════════════════════════════════════════════════
QUICK DEPLOYMENT STEPS:
═══════════════════════════════════════════════════════════════════

1. Upload tina-bakery-hostinger.zip to Hostinger (cPanel File Manager or FTP)

2. Extract ZIP file in public_html/

3. SSH to server and run:
   cd ~/public_html/tina-bakery-hostinger-deploy
   pnpm install --prod
   npx prisma generate
   npx prisma migrate deploy

4. Create .env file with your environment variables
   nano .env
   [Paste values from ENVIRONMENT_VARIABLES_TEMPLATE.txt]

5. Start application:
   npm start
   Or use cPanel Node.js App setup

6. Verify: https://yourdomain.com

For detailed instructions, see HOSTINGER_DEPLOYMENT_ASSESSMENT.md
